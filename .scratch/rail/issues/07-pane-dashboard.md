# 07: 面板改成儀表板

**What to build:** 面板不再是遙控器，而是看進度用的儀表板：一眼看出功能走到哪裡、哪些步驟被跳過；目前步驟的卡片上只留「跳過」和「我卡住了」。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 拿掉「填入指令」和「做完了」兩個按鈕
- [ ] 目前步驟的卡片上有「跳過」（效果跟 `/matt-flow skip` 一樣）和「我卡住了」（照舊預填 `/ask-matt`）
- [ ] 跳過的步驟和通過的步驟，顯示方式明顯不同
- [ ] 保留等級按鈕、context 用量計、已完成的功能數
- [ ] 在 terminal、desktop、vscode、mobile 四種介面都畫得出來
- [ ] 證據：完成時在本檔底下加「## 證據」，貼上新增測試先失敗、後通過的輸出，以及測試框架畫出來的面板文字
- [ ] 證據截圖（由人截）：真實終端機裡的面板，要看得到至少一個跳過的步驟，以及目前步驟卡片上的兩個按鈕。截圖存放在本功能的 evidence 資料夾（只留在本地），本檔記錄檔名和截到的內容
