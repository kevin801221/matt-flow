# 05: 系統提示

**What to build:** Claude 每一輪都會在系統提示裡看到自己在流程的哪裡：目前的功能、等級、步驟，現在哪些動作會被擋、各自怎麼解鎖，以及交棒的規矩。這樣 Claude 的建議會跟面板一致，也不會去嘗試一定會被擋的動作。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 做過 setup、軌道開著的專案裡，系統提示最後多一段（session 範圍）
- [ ] 內容包括：功能和它的名稱（如果已經有）、等級、目前的步驟、現在被擋的動作和各自的解鎖指令
- [ ] 內容包括規矩：每次交棒都要停下來，把下一步的指令告訴人；除了下一步的指令，不建議其他流程指令；絕不繞過任何阻擋，包括透過 Bash
- [ ] 沒做過 setup，或軌道關掉時，不加這一段
- [ ] 證據：完成時在本檔底下加「## 證據」，貼上新增測試先失敗、後通過的輸出，以及這段系統提示在三種情況下的實際文字：沒有功能、規格寫好但還沒切卡、動手做中
