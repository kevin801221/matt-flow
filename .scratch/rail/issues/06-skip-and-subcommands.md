# 06: 跳過與子指令

**What to build:** 人永遠有脫離軌道的方法：跳過一個步驟、結束一個功能，或在這個專案整個關掉軌道。人跳步輸入指令時不會被擋，只會收到提醒，被跳過的步驟會如實記錄。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 只輸入 `/matt-flow` 時，照舊開關面板
- [ ] `/matt-flow skip`：目前的步驟記為跳過，回一行訊息說明下一步
- [ ] `/matt-flow end`：結束目前的功能，回一行訊息
- [ ] `/matt-flow off` 和 `/matt-flow on`：在這個專案關閉或開啟軌道；關掉時，程式碼關卡和 commit 關卡全部安靜
- [ ] 人輸入某個步驟的指令，而等級裡更前面的步驟還沒通過時：指令照常執行，跳出提示列出被視為跳過的步驟，並把它們記為跳過
- [ ] 證據：完成時在本檔底下加「## 證據」，貼上新增測試先失敗、後通過的輸出
