# 02: 功能的生命週期與通過規則

**What to build:** 功能會自己開始、自己結束；每個步驟依照規格裡的規則判斷通過，有產出物的看產出物，沒有的看 skill 有沒有跑過。步驟通過時跳出提示，並預填下一步的指令。從面板和狀態列都看得到效果。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 沒有進行中的功能時，任何流程步驟的 skill（setup 除外）一跑，就開始一個功能
- [ ] 動手做只在人輸入 `/implement` 或 `/implement-spec` 時通過；模型自己執行 `tdd` 不會讓它通過
- [ ] 本地 markdown tracker：功能資料夾裡有規格檔，「寫成規格書」才通過；至少有一個任務卡檔案，「切成任務卡」才通過；只輸入 `/to-spec` 不算通過
- [ ] GitHub 或 GitLab tracker：這兩個步驟在 skill 跑過時通過
- [ ] tracker 的種類從 tracker 設定檔的標題判斷
- [ ] 產出物在每一輪結束時檢查；規格產生後，功能以規格所在的資料夾名稱稱呼
- [ ] 步驟通過時跳出提示，並在這一輪結束時預填下一步的指令
- [ ] 複盤通過時功能結束：已完成的功能數加一，setup 以外的步驟全部重設
- [ ] 證據：完成時在本檔底下加「## 證據」，貼上新增測試先失敗、後通過的輸出，以及一張 mermaid 狀態圖（步驟：未通過 → 通過 / 跳過；功能：沒有 → 進行中 → 結束）
